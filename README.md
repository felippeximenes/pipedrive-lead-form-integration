# Pipedrive Lead Form Integration (HTML + JS + Netlify Functions)

Este projeto demonstra uma **integração completa entre um formulário web e o CRM Pipedrive**, utilizando **HTML e JavaScript puro no frontend** e **Netlify Functions no backend**, com foco em **boas práticas de segurança, versionamento e arquitetura**.

O fluxo implementado simula um cenário real de negócios:
**Lead → Pessoa (Contact) → Deal (Negócio) no Pipeline do Pipedrive**.

## Objetivo do Projeto
Demonstrar, de forma didática e prática:
- Integração com API externa (Pipedrive)
- Uso de Serverless Functions
- Proteção de credenciais via variáveis de ambiente
- Versionamento em etapas (branches)
- Boas práticas de integração com CRM

Projeto desenvolvido com **foco educacional e demonstrativo**, alinhado a desafios reais de mercado.
